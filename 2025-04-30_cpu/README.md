# BitNet.cpp

Uses [BitNet.cpp](https://github.com/microsoft/BitNet). 

Uses BitNet code base as of 2025-04-30 (c17d1c5d77c48af7d6fb29c9f28a3da0277fc394).

## Quick start

### Inhouse registry

* Log into registry using *public* credentials:

  ```bash
  docker login -u public -p public public.aml-repo.cms.waikato.ac.nz:443 
  ```

* Pull and run image (adjust volume mappings `-v`):

  ```bash
  docker run --shm-size 8G --net=host \
    -v /local/dir:/container/dir \
    -it public.aml-repo.cms.waikato.ac.nz:443/llm/bitnet:2025-05-30_cpu
  ```

### Docker hub

* Pull and run image (adjust volume mappings `-v`):

  ```bash
  docker run --shm-size 8G --net=host \
    -v /local/dir:/container/dir \
    -it waikatodatamining/bitnet:2025-05-30_cpu
  ```

### Build local image

* Build the image from Docker file (from within /path_to/bitnet/2025-05-30_cpu)

  ```bash
  docker build -t bitnet .
  ```
  
* Run the container

  ```bash
  docker run --shm-size 8G --net=host -v /local/dir:/container/dir -it bitnet
  ```
  `/local/dir:/container/dir` maps a local disk directory into a directory inside the container


## Publish images

### Build

```bash
docker build -t bitnet:2025-05-30_cpu .
```

### Inhouse registry  

* Tag

  ```bash
  docker tag \
    bitnet:2025-05-30_cpu \
    public-push.aml-repo.cms.waikato.ac.nz:443/llm/bitnet:2025-05-30_cpu
  ```
  
* Push

  ```bash
  docker push public-push.aml-repo.cms.waikato.ac.nz:443/llm/bitnet:2025-05-30_cpu
  ```
  If error "no basic auth credentials" occurs, then run (enter username/password when prompted):
  
  ```bash
  docker login public-push.aml-repo.cms.waikato.ac.nz:443
  ```

### Docker hub  

* Tag

  ```bash
  docker tag \
    bitnet:2025-05-30_cpu \
    waikatodatamining/bitnet:2025-05-30_cpu
  ```
  
* Push

  ```bash
  docker push waikatodatamining/bitnet:2025-05-30_cpu
  ```
  If error "no basic auth credentials" occurs, then run (enter username/password when prompted):
  
  ```bash
  docker login
  ```

## Permissions

When running the docker container as regular use, you will want to set the correct
user and group on the files generated by the container (aka the user:group launching
the container):

```bash
docker run -u $(id -u):$(id -g) -e USER=$USER ...
```

## Caching

* Create the following directories:

  ```bash
  mkdir cache triton
  ```

* when running the container as current user

  ```bash
    -v `pwd`/cache:/.cache \
    -v `pwd`/triton:/.triton \
  ```


## Scripts

The following additional scripts are available:

* `huggingface-cli` - for exporting template config files and setting parameters (calls the `/opt/BitNet.env/bin/huggingface-cli`)
* `bitnet_run_inference` - for exporting template config files and setting parameters (calls the `/opt/BitNet/run_inference.py` script)


## Example

```bash
mkdir cache triton models logs

docker run --shm-size 8G --net=host \
    -u $(id -u):$(id -g) -e USER=$USER \
    -v `pwd`:/workspace \
    -v `pwd`/cache:/.cache \
    -v `pwd`/triton:/.triton \
    -it waikatodatamining/bitnet:2025-05-30_cpu

huggingface-cli download microsoft/BitNet-b1.58-2B-4T-gguf \
    --local-dir /workspace/models/BitNet-b1.58-2B-4T

bitnet_run_inference \
    -m /workspace/models/BitNet-b1.58-2B-4T/ggml-model-i2_s.gguf \
    -p "You are a helpful assistant" \
    -cnv
```
